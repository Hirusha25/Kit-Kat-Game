# Dunk the Break — hazard recolour prompts (reference palette)

The reference uses cool, saturated hazards so they pop against the red: **royal blue** alarm clock, **teal/cyan** phone, **violet/purple** calendar and envelope, with the wafers and gold wafer staying warm. One prompt per asset. Attach the current PNG from `assets/img/game/` and paste the prompt. Output: transparent PNG, 300 x 300 px, centred, soft studio light from the top-left, no ground shadow, no text other than what the prompt names.

Keep the same camera angle, size and framing as the attached file so it drops in without any code change.
